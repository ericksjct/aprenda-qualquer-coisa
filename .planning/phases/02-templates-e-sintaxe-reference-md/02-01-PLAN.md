  <action>
Criar um script sh que recebe um path de arquivo markdown como `$1` (default
`mentor/reference.md`) e imprime no stdout SO as linhas que estao DENTRO de blocos
cercados (entre uma linha que comeca com tres crases e a proxima linha de fechamento
de tres crases), excluindo as proprias linhas de cerca.

Logica (toggle de estado): percorrer linha a linha; ao encontrar uma linha cujo conteudo
(apos trim) comeca com tres crases, alternar o flag `dentro`. Quando `dentro` estiver
ligado e a linha NAO for uma cerca, imprimir a linha. Implementar com `awk` (mais robusto
que loop de shell):

```sh
#!/usr/bin/env sh
# extract-fenced.sh — imprime SO o conteudo dentro de blocos cercados (```), sem as cercas.
# Uso: sh extract-fenced.sh [arquivo.md]   (default: mentor/reference.md)
FILE="${1:-mentor/reference.md}"
awk '
  /^[[:space:]]*```/ { inside = !inside; next }
  inside { print }
' "$FILE"
```

Garantir que e POSIX-sh / Git Bash compativel (sem bashisms). Nao usar acentos em
comentarios (convencao do repo: portugues sem acentos).
  </action>
